# Pixel Editor

**Версия 1.0.0** (проект развивается, пул-реквесты приветствуются) · Лицензия: GPL-3.0-or-later · Copyright (C) 2026 mrl4an · [English version](README.md)

Лёгкий редактор пиксель-арта и спрайтов для Windows (WPF, .NET 10) с полным набором инструментов для ИИ-агентов.
Прозрачность бинарная: пиксель либо есть, либо пустой. Вся логика лежит в `PixelEditor.Core`, поэтому те же операции доступны в редакторе,
из командной строки (`pixed`) и через MCP-сервер (`pixed-mcp`) для ИИ-помощников.

- **Редактор:** слои, карандаш, ластик, заливка (с допуском), пипетка, фигуры, градиент, «светлее / темнее», текст, выделения (рамка, палочка, лассо, по точкам),
  перемещение, ручки растягивания и вращения как в Paint, палитры, запоминание инструмента между запусками, светлая и тёмная темы, русский и английский интерфейс (переключается на лету).
- **Анимация и игровые форматы:** листы спрайтов, экспорт GIF, состояния RSI (Space Station 14) с `meta.json`, экспорт для Unity (Aseprite JSON) и Godot 4 (`SpriteFrames` `.tres`),
  шаблоны анимаций (покой, ходьба на 4 и 8 сторон, атака, дверь и свои).
- **Обработка:** 48 операций (уменьшение разными способами, квантование, палитры, вырезание, контур, цвет и форма, чистка цветовой крошки...), 11 проверок результата,
  12 встроенных шаблонов (пайплайнов) и своя библиотека шаблонов и палитр.
- **Для ИИ:** работает даже с обычным чатом (скопировали запрос, вставили JSON-ответ, предпросмотр, применили) и с агентами: CLI и MCP с теми же возможностями, 32 MCP-инструмента, журнал ошибок, который агент читает сам. Людям: [docs/ru/AI-TOOLS-HOWTO.md](docs/ru/AI-TOOLS-HOWTO.md); агентам: [docs/AI-GUIDE.md](docs/AI-GUIDE.md).

## Сборка и запуск

**Быстрый старт:** дважды щёлкните `PixelEditor.cmd` в этой папке. При первом запуске он соберёт редактор в `app\`, а потом **пересобирает сам, если исходники новее**, поэтому старая версия не запустится (нужны .NET 10 SDK и Windows). `build.cmd` делает полную свежую сборку: редактор в `app\`, ИИ-инструменты в `tools\` (`--test` сначала гоняет тесты, `--clean` удаляет старый результат, `--gui` собирает только редактор). Впервые в редакторе? Прочитайте [docs/ru/USER-GUIDE.md](docs/ru/USER-GUIDE.md).

Из терминала:

```
dotnet build
dotnet run --project src/PixelEditor.App
dotnet test tests/PixelEditor.Tests
dotnet test tests/PixelEditor.ViewModels.Tests
dotnet run --project tests/PixelEditor.GuiSmoke     # открывает окно, нужен рабочий стол
```

Публикация ИИ-инструментов в одну папку:

```
dotnet publish src/PixelEditor.Cli -c Release -o <папка>
dotnet publish src/PixelEditor.Mcp -c Release -o <папка>
claude mcp add pixel-editor -- "<папка>\pixed-mcp.exe"
```

Данные пользователя (настройки, палитры, шаблоны, автосохранение) лежат в `%AppData%\PixelEditor`; переменная окружения `PIXED_DATA_DIR` переопределяет папку.

**Журнал ошибок:** каждый сбой записывается (по-английски, со стеком) в `%AppData%\PixelEditor\logs\pixed-ГГГГММДД.log`. Открыть папку: **Справка → Открыть папку журнала ошибок**;
ИИ-агент читает журнал командой `pixed log` или MCP-инструментом `read_log`. `pixed --version` печатает версию.

| Проект | Назначение |
|---|---|
| `src/PixelEditor.Core` | Библиотека без UI: пиксели, слои, undo, выделение, рисование, листы, GIF, RSI, операции, проверки, пайплайны, плагины, тексты, журнал |

| `src/PixelEditor.ViewModels` | Модели представления (MVVM без WPF): вся логика интерфейса, локализация |
| `src/PixelEditor.App` | Представление WPF (`PixelEditor.exe`) |
| `src/PixelEditor.Cli` | `pixed.exe`, командная строка для агентов и скриптов |
| `src/PixelEditor.Mcp` | `pixed-mcp.exe`, MCP-сервер (stdio) |
| `tests/*` | xUnit-тесты ядра и моделей, смоук-тест GUI |
| `scripts/audit_ai_access.py` | Вызывает каждую операцию, проверку, шаблон и MCP-инструмент: доказывает, что ИИ всё доступно |
| `pipelines/`, `plugins-sample/`, `examples/` | Примеры шаблонов, плагина, сцен и фото |

## Основы редактора

- **Инструменты (слева):** карандаш `B`, ластик `E`, заливка `G`, пипетка `I`, фигуры `L R O`, выделение `M W S P`, перемещение `V`, градиент `D`, светлее/темнее `U`, текст `T`.
  ПКМ по кнопкам «Фигуры» и «Выделение» открывает выбор варианта. `Alt+клик` пипетка, `X` меняет цвета.
- **Выделения:** после выделения включается «Переместить»: тяните внутри для переноса, за квадратики для растягивания и сжатия (Shift у углов сохраняет пропорции),
  возле угла снаружи для вращения (Shift: шаг 15°). Пресеты: 90° влево и вправо, 180°, любой угол.
- **Вид:** колесо масштабирует вокруг курсора, `Пробел`+перетаскивание двигает холст, `F` вписывает холст в окно.
- **Слои:** каждая фигура, вставка и текст по умолчанию идут на свой слой (меню «Правка»).
- **Палитры и цвета:** библиотека палитр, панель используемых цветов, импорт и экспорт `.hex` и `.gpl`.
- **Импорт:** `Ctrl+I` или перетаскивание картинки в окно: уменьшение разными способами, квантование, очистка и контур, предпросмотр.
- **Автоматизация (меню «Шаблоны»):** запуск шаблонов на текущем или всех слоях, пакетная обработка папки, свой шаблон в конструкторе.
- **Язык:** кнопка `RU`/`EN` рядом с переключателем темы. Дополнительные языки: положите JSON-файл с кодом языка в имени в `%AppData%\PixelEditor\locales`.

## Пайплайны и проверки

Шаблон это JSON со списком `steps` (операции) и `checks` (критерии годности):

```json
{ "name": "photo-to-sprite",
  "steps": [
    { "op": "trim" },
    { "op": "resize", "width": 32, "method": "mode" },
    { "op": "alphaThreshold", "value": 128 },
    { "op": "quantize", "colors": 16 },
    { "op": "despeckle", "maxArea": 3, "diagonal": false },
    { "op": "outline", "color": "#000000" } ],
  "checks": [ { "check": "maxColors", "value": 16 }, { "check": "binaryAlpha" } ] }
```

Запуск: `pixed run photo-to-sprite.json in.png out.png` (коды выхода: 0 успех, 1 ошибка, 2 проверки не пройдены) или по имени встроенного шаблона.
Полные каталоги: `pixed ops`, `pixed checks`, `pixed templates`, `pixed palettes`.

## Плагины

Своя операция или проверка это класс в DLL, реализующий `IPixelOperation` или `IPixelCheck` из `PixelEditor.Core.Plugins`.
Положите DLL в папку `plugins` рядом с программой или в `%AppData%\PixelEditor\plugins` (у CLI ещё `--plugins <папка>`).
Пример: `plugins-sample/SymmetryPlugin`. Плагин выполняется с правами приложения: подключайте только проверенные DLL.
