# Разбор инструментов: что есть, чего не хватает пользователю

Цель: **не супер продвинутый редактор, но удобный и с нужными инструментами**. Сравнение по общеизвестным возможностям Aseprite, LibreSprite, Piskel, Pixelorama и GraphicsGale (без обращения к их исходникам). Принцип отбора: берём то, чем пользуются каждый день, и не берём то, что нужно редким профессионалам или ломает наши ограничения (бинарная прозрачность, только пиксели).

## 1. Что уже есть

| Область | Есть |
|---|---|
| Рисование | карандаш, ластик (размер до 16, симметрия по двум осям), заливка, линия, прямоугольник, эллипс (толщина, заливка), градиент (дизеринг, ступени, плавный), «Светлее / темнее», текст (свой шрифт 5×7, русский), подсветка области под кистью |
| Выделение | рамка, волшебная палочка (допуск, связная область или весь слой, добавление), лассо, выделение по точкам; перенос, копирование, вырезание, поворот, отражение, ×2 и ÷2; обрезка холста по выделению; координатная сетка выделения |
| Слои | добавить, дубль, порядок, слить вниз, видимость, замок, миниатюры; новый слой для каждой фигуры, вставки и текста |
| Цвет | RGB и hex, основной и дополнительный цвет, палитры (системные и свои, библиотека, импорт и экспорт), список используемых цветов с заменой |
| Холст | размер холста и размер изображения (способы уменьшения), обрезка по содержимому, импорт с даунскейлом, вставка из буфера |
| Автоматизация | шаблоны (системные, свои, конструктор), 35+ операций, проверки, пакетная обработка, предпросмотр результата, сцена из примитивов, CLI и MCP |
| Анимация | лист с зонами, RSI, предпросмотр по строкам, задержки по кадрам, экспорт для Unity, Godot, GIF |

## 2. Чего не хватает (по пользе для повседневной работы)

Оценка: **польза** (как часто нужно), **цена** (сложность у нас), **решение**.

### Нужно сделать (высокая польза, разумная цена)

| № | Возможность | Почему | Цена | Заметки |
|---|---|---|---|---|
| 1 | **Пиксель-перфект при рисовании от руки** | быстрые штрихи оставляют «уголки» (L-образные лишние пиксели); во всех пиксельных редакторах это галочка | малая | в `PointerMove` для карандаша убирать угловой пиксель; опция в параметрах карандаша |
| 2 | **Инструмент «Заливка» с допуском и режимом «весь слой»** | палочка это умеет, заливка нет; нужна заливка по похожему цвету и по всем пикселям цвета | малая | переиспользовать `SelectionMask.Wand` |
| 3 | **Режим тайлов (рисование бесшовной текстуры)** | убрали окно предпросмотра вместе с 3×3; для тайлов и текстур это основная функция Aseprite | средняя | не отдельное окно, а режим холста: показ соседних копий вокруг, рисование заворачивается через края |
| 4 | **Кальки (луковая шкура)** | рисовать кадры без неё очень трудно | средняя | показывать соседние кадры листа полупрозрачным контуром, вкл/выкл |
| 5 | **Сделать палитру градации (рампу)** | быстро получить 4-5 оттенков одного цвета для теней и бликов | малая | кнопка у цвета: «Оттенки»: тёмный, основной, светлый; добавляет в палитру |
| 6 | **Выбор цвета HSV (круг или квадрат оттенка/насыщенности)** | RGB-ползунки неудобны для подбора оттенка | средняя | цветовое поле + ползунок оттенка рядом с hex |
| 7 | **Инвертировать, расширить и сузить выделение** | после палочки нужно «всё кроме» и подправить границу | малая | операции над `SelectionMask` |
| 8 | **Пробел для перемещения холста** и **центрировать/вписать (кнопка)** | привычное управление, без него неудобно на больших холстах | малая | клавиша `Space` + кнопка «Вписать» в статус-баре |
| 9 | **Референс-картинка под холстом** | рисовать по образцу без вставки в слой | средняя | отдельное изображение с прозрачностью, не попадает в экспорт |
| 10 | **Отмена для имени, видимости, замка слоя** | сейчас не откатываются (есть в списке недоделок) | малая | через `DelegateAction` |

### Стоит рассмотреть (польза средняя)

| Возможность | Комментарий |
|---|---|
| **Режим «замены цвета» кистью** | красить только пиксели выбранного цвета: удобно перекрашивать детали |
| **Прозрачность слоя и режим наложения (умножение)** | для теней это идеал, но ломает бинарную прозрачность и ограничение палитры: делать только как предпросмотр, экспорт склеивать в бинарный; решение отложить |
| **Копирование между состояниями RSI и кадрами** | копировать кадр целиком (ячейку листа) на следующий одним действием |
| **Нарезка листа на слои и обратно** | частично есть (импорт листа, экспорт слоёв как лист) |
| **Быстрые клавиши в одном месте и подсказки при наведении** | подсказки есть, окно со списком горячих клавиш нет |
| **Свободный поворот выделения (с пиксельным алгоритмом)** | нужен для спрайтов с вращением; есть 90°, свободный сложен и часто портит пиксели |

### Не делать (низкая польза или противоречит принципам)

| Возможность | Почему не нужна |
|---|---|
| Кисти с мягкими краями, прозрачность кисти, размытие, градиентные карты | противоречит бинарной прозрачности и пиксельной чёткости |
| Полноценная таймлайн-анимация с ячейками-слоями, связанными ячейками | лист с зонами проще и понятнее; для движков экспорт уже есть |
| 2D-кости и меши | для пиксель-арта почти не применяются (ломают сетку), отложено |
| Индексированный режим цветов (палитра как источник правды) | сложный перенос, большинству не нужен; библиотека палитр покрывает основное |
| Чтение и запись `.aseprite`, `.psd` | дорогая поддержка форматов; достаточно PNG, листов, GIF и RSI |
| Карта освещения и динамический свет | для пиксель-арта проще рисовать руками; есть «Свет и тень по краям»; карта нормалей имеет смысл только для движка |

## 3. Предлагаемый порядок работ

1. Быстрые победы (малая цена, заметный эффект): **№1 пиксель-перфект, №2 заливка с допуском, №5 рампа оттенков, №7 инверсия выделения, №8 пробел и «вписать», №10 отмена для слоёв.**
2. Работа с цветом: **№6 HSV-выбор цвета.**
3. Рисование кадров и тайлов: **№4 калька, №3 режим тайлов.**
4. Удобство работы с образцом: **№9 референс.**

Каждый пункт малой цены это 1-3 дня работы с тестами по нашей схеме (логика в `ViewModels` или `Core`, окно только показывает).

## 4. Что проверить с пользователями

- Нужен ли им слой с прозрачностью и умножением, или хватает «Светлее / темнее» и «Свет и тень по краям».
- Достаточно ли листа с зонами для анимации, или нужна полноценная лента кадров под холстом.
- Какие 5-7 горячих клавиш они хотят иметь «как в Aseprite».
