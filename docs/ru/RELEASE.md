## P2: продукт (из docs/ru/IMPROVEMENTS.md)

- Отмена переименования, видимости и замка слоя (E6); калька (E7); режим тайлов (E8); HSV-выбор цвета (E9); референс под холстом (E10); разная длина строк листа (E11); копирование кадра (E12); обзор и проверка RSI (E13, E14); окно горячих клавиш (E15); недавние цвета (E16).
- Упрощения: объединить «Переместить» и «Выделение», сократить встроенные шаблоны до 6-7, три пресета импорта, ужать меню «Операции».
- Ограничения качества: `cutout` не отделяет предмет от фона того же тона и текстуры (лиса на снегу): нужен `polygonMask` или сегментация вроде GrabCut; `cleanEdges` убирает ореол только при заданном `matte`; поворот линий в 1-2 px на произвольный угол рваный (RotSprite).
- ИИ-инструменты: `view_image` и `fetch_image` только в MCP; команды не раскрывают `*`.
- Код: `AGENTS.md` длинный, разбить по областям; английская таблица текстов ядра ключуется русскими строками.

## Чек-лист релиза (когда P0 и P1 закрыты)

1. `dotnet build -c Release`, все тесты зелёные, смоук GUI зелёный на чистой машине.
2. `python scripts/audit_ai_access.py <папка публикации>` печатает «всё доступно».
3. Self-contained публикация, zip, контрольная сумма, установщик; запуск на чистой Windows 11 без .NET.
4. Обновить версию, журнал изменений, скриншоты в README; поставить тег; опубликовать описание релиза.
