# Работа с ИИ-инструментами: инструкция для человека

Эта страница для **вас**: вы хотите, чтобы ИИ-помощник (Claude Code, Claude Desktop или любой MCP-клиент) обрабатывал, рисовал и экспортировал спрайты в Pixel Editor.
Сам агент читает [AI-GUIDE.md](../AI-GUIDE.md) (только на английском); здесь описано, как всё настроить и что просить.

English version: [../AI-TOOLS-HOWTO.md](../AI-TOOLS-HOWTO.md).

## 1. Что умеет агент

| Возможность | Как это делается |
|---|---|
| Почистить спрайт, убрать фон и контур, сократить цвета, привести к палитре | готовые шаблоны и 48 операций |
| Превратить фото в пиксель-арт | шаблон «Picture from the internet to 64 px pixel art» или свой шаблон |
| Нарисовать плейсхолдер (персонаж, сундук, зверь) | `draw` с коротким JSON-описанием сцены, около 200 токенов вместо работы по пикселям |
| Обработать целую папку | `batch` с одним шаблоном и отчётом по каждому файлу |
| Собрать лист спрайтов, GIF, файлы анимации для Unity и Godot | `sheet`, `gif`, `anim-export` |
| Подогнать картинку под стиль готового спрайта | `style-extract` и `style-apply` |
| Доказать, что результат годный | **проверки** (лимит цветов, бинарная прозрачность, нет мусора...) |

Три входа, выберите один:

| Вход | Когда |
|---|---|
| **MCP-сервер** `pixed-mcp.exe` | помощник поддерживает MCP: с каждым ответом приходит картинка |
| **Командная строка** `pixed.exe` | любой агент с доступом к оболочке; скрипты и пакетные задачи |
| **DLL** | своя программа на .NET |

## 2. Установка

1. Получите папку с инструментами. Из релиза: распакуйте zip. Из исходников (нужен .NET 10 SDK, Windows):

   ```powershell
   dotnet publish src/PixelEditor.Cli -c Release -o C:\tools\pixed
   dotnet publish src/PixelEditor.Mcp -c Release -o C:\tools\pixed
   ```

   Папка должна быть **без пробелов в пути**: это избавляет от проблем с кавычками. Положите в неё `docs\AI-GUIDE.md`: агент прочитает его оттуда.
2. Проверьте, что всё доступно (по желанию, около минуты):

   ```powershell
   python scripts\audit_ai_access.py C:\tools\pixed
   ```

   Последняя строка должна сообщить, что всё доступно.
3. `C:\tools\pixed\pixed.exe --version` покажет версию и лицензию.

## 3. Подключение помощника

**Claude Code (MCP):**

```powershell
claude mcp add pixel-editor -- "C:\tools\pixed\pixed-mcp.exe"
```

Перезапустите сессию и выполните `/mcp`: `pixel-editor` должен быть подключён, 32 инструмента.

**Claude Desktop:** добавьте в `claude_desktop_config.json` и перезапустите программу:

```json
{ "mcpServers": { "pixel-editor": { "command": "C:\\tools\\pixed\\pixed-mcp.exe" } } }
```

**Без MCP (только командная строка):** подключать нечего. Скажите агенту, где папка, и что нужно прочитать `AI-GUIDE.md` (примеры ниже).

Полезные переменные окружения (задайте до запуска помощника): `PIXED_LANG=ru` русские сообщения, `PIXED_DATA_DIR=<папка>` хранить шаблоны, палитры и журнал в другом месте,
`PIXED_PLUGINS=<папка>;<папка>` DLL с плагинами.

## 4. Как ставить задачи: готовые запросы

Укажите **что нужно, где файлы, куда писать результат и как измерить успех**. Измеримое правило позволяет агенту подтвердить результат проверками, а не гадать.

**Почистить спрайт**

> Инструменты в `C:\tools\pixed`, прочитай там `AI-GUIDE.md`. Почисти `C:\art\hero.png` шаблоном "Clean up sprite", результат запиши в `C:\art\out\hero.png`.
> Нужно не больше 16 цветов, бинарная прозрачность и ни одного одинокого пикселя. Покажи результат в увеличении ×8.

**Фото в пиксель-арт** (скачивать агент может только то, что вы разрешите)

> Сделай пиксель-арт 64 px из `C:\art\fox.jpg` (фон трава, автоматическое вырезание может не справиться: тогда обведи предмет через `polygonMask`).
> Сохрани свой шаблон как "fox-64", чтобы я мог его использовать снова. Исходный файл не перезаписывай.

**Целая папка**

> Прогони шаблон "Remove background and clean edges" по всем PNG из `C:\art\raw`, результаты в `C:\art\clean`. Назови файлы, где проверки не прошли.

**Плейсхолдеры**

> Нарисуй через `draw_scene` стражника 24×32 в шлеме с копьём (JSON-сцена, не по пикселям). Покажи и один раз поправь пропорции.

**Анимация для игры**

> Нарежь `C:\art\walk.png` (ячейки 32×32), собери кадры в лист со строками "down, up, left, right" и экспортируй для Godot 4 и Unity в `C:\export\walk`.

**Проверить, справляется ли агент с инструментами** (хороший первый запуск): попросите найти CC0-картинку животного, скачать её через `pixed fetch`, выбрать шаблон, написать свой шаблон с 3-4 проверками,
довести до кода выхода 0, сохранить шаблон в библиотеку и запустить его по имени. Затем попросите короткий отчёт: число вызовов, ошибок и мест в руководстве, где он запутался.

## 4b. Нет агента? Подойдёт любой обычный чат с ИИ

MCP, агент и даже командная строка не нужны. Пайплайн может написать любой чат (веб-чат, приложение на телефоне), а редактор его применит:

1. В редакторе выберите **Шаблоны → Из чата с ИИ…** (одно окно на всю работу) и нажмите **Скопировать запрос**. В запросе формат, полный список операций и проверок, правила, дающие хороший результат, и размер вашей текущей картинки.
2. Откройте любой чат с ИИ, **вставьте запрос**, затем **приложите фото** и напишите, что нужно («пиксель-арт 64 px, 16 цветов, чёрный контур, убери фон»).
3. Чат ответит блоком JSON. Скопируйте ответ целиком, вернитесь в то же окно, щёлкните по большому полю и нажмите **Ctrl+V**. Текст сам превратится в чистый JSON, а результат запомнится как вариант.
4. Редактор сам найдёт JSON внутри ответа (пояснения и markdown не мешают), проверит каждое имя операции и параметр и напишет «Готово: шагов N, проверок M». JSON остаётся **доступным для правки**: поменяйте число или цвет руками, и предпросмотр *До / После* справа обновится сам, а шаги и проверки видны в разделе *Шаги и проверки*. Пока вы не нажмёте **Применить**, картинка не меняется.
5. Не уверены, какой ответ лучше? Вставьте другой ответ (каждый новый запоминается как вариант сам, одинаковые не дублируются) или поправьте JSON и нажмите **Запомнить вариант** (кнопка видна только для ещё не сохранённого результата), затем сравните миниатюры в *Вариантах для сравнения*; щелчок по варианту возвращает его JSON, затем **Применить** лучший.
6. Понравилось? **Сохранить как шаблон…** оставит пайплайн в «Мои шаблоны», и его можно запускать на любых других картинках.

Если в ответе ошибка (выдуманное имя операции, сломанный JSON), диалог покажет её с подсказкой («возможно, вы имели в виду resize») чтобы вы исправили его руками или попросили чат переделать и вставили новый ответ.

То же из командной строки: `pixed chat-prompt --image photo.png > prompt.txt` создаёт запрос, `pixed pipeline-check answer.txt` проверяет сохранённый ответ, а `pixed run answer.txt photo.png out.png` запускает его (в текстовом файле может быть ответ чата целиком).

Советы: сообщите чату настоящий размер картинки, если он отличается от указанного в запросе; для фото с пёстрым фоном попросите обвести предмет через `polygonMask` и дать координаты; если чат пишет слишком много лишнего, попросите «только один блок JSON».

## 4c. Нарисовать спрайт или целый лист в обычном чате (без референса)

Это же окно **Шаблоны → Из чата с ИИ…** умеет просить чат РИСОВАТЬ с нуля из примитивов (прямоугольники, эллипсы, линии, многоугольники):

1. В окне выберите, что просить: **Нарисовать спрайт** (одна картинка) или **Нарисовать лист кадров** (несколько направлений и кадров анимации в одном ответе), затем нажмите **Скопировать запрос**.
2. Вставьте запрос в любой чат с ИИ и опишите, что нужно: «стражник в синем плаще, 24x32, идёт в 4 направлениях, три кадра ходьбы». Свои кадры тоже можно: «добавь строку атаки из 4 кадров, меч опускается вниз».
3. Вставьте ответ обратно (Ctrl+V). Окно найдёт JSON, проверит его (опечатка в названии фигуры показывается с местом, например «Строка S, кадр 2: ... возможно, ellipse») и покажет живой предпросмотр. JSON можно править руками: фигуры уложены по одной в строку.
4. Нажмите **Добавить слоем** (спрайт ляжет новым слоем, холст вырастет, если спрайт больше) или **Открыть как лист** (новый лист анимации, где уже заданы сетка, названия строк, названия кадров и задержки; экспорт в меню «Анимация»). Спрайт можно открыть и **Новым документом**.
5. Не нравится? Вставьте другой ответ (каждый запоминается вариантом для сравнения) или попросите чат исправить и вставьте снова.

**Раскладка следует вашему выбору.** Для *Нарисовать лист кадров* в окне есть компактный выбор **раскладки листа** (те же шаблоны, что в *Новом листе анимации*, и ваши; последний выбран заранее), размер кадра и необязательная задержка для всех кадров; запрос ТРЕБУЕТ именно эту раскладку (размер кадра, названия строк по порядку, названия кадров, задержки), и пример в нём построен по ней. Если текущий документ уже лист анимации или состояние RSI, обязательной становится его раскладка, а выбор скрыт. Если ответ отличается (другие строки, число кадров или размер), окно напишет, что ожидалось и что пришло, но предпросмотр и открытие остаются доступны. Названия кадров и задержки, которых нет в ответе, берутся из запрошенной раскладки; заданные в ответе главнее. Если сетка ответа совпала с сеткой текущего листа, главная кнопка **Нарисовать в этом листе** (строки, названия кадров и задержки листа сохраняются, Отмена работает), а **Открыть новым листом** становится второй.
Лист описывается коротко: тело кладут в `base`, а в каждом кадре перечисляют только отличия (ноги). Строка может быть зеркалом другой (`"W": mirrorOf "E"`) или копией, кадры можно сдвигать (`offset`) и повторять (`copyOf`).
То же из командной строки: `pixed chat-prompt --kind sheet` создаёт запрос (с `--template walk-4` или `--rows idle,attack --frames stand:0.5,swing:0.1 --size 32x32 --delay 0.2` запрос требует эту раскладку), `pixed pipeline-check answer.txt` проверяет ответ (напишет Sprite или Sheet), `pixed draw answer.json out.png` рисует спрайт, `pixed draw-sheet answer.json out.png` лист.

## 5. Чего ожидать

- Коды выхода: **0** успех, **1** ошибка, **2** шаги выполнены, но проверка не пройдена (картинка записана, агент может на неё посмотреть и поправить шаблон).
- Шаблоны, которые сохранил агент, лежат в `%AppData%\PixelEditor\pipelines` и появляются в меню редактора **Шаблоны → Мои шаблоны**; палитры в `%AppData%\PixelEditor\palettes`.
- Агент пишет только в названные вами пути и скачивает только с вашего разрешения. Скажите ему об этом прямо.
- Автоматическое вырезание (`cutout`) слабо работает, когда предмет и фон одного тона и текстуры; тогда агенту нужен `polygonMask`.
- Плагины это чужой код с полными правами: подключайте только DLL, которые вы написали или проверили.

## 6. Если что-то не работает

| Проблема | Что делать |
|---|---|
| Помощник не показывает `pixel-editor` | проверьте путь в команде, перезапустите помощника, один раз запустите `pixed-mcp.exe` из терминала (он ждёт ввода, выйдите по Ctrl+C) |
| «exe не найден» | дайте агенту полный путь к `pixed.exe`; соберите инструменты в папку без пробелов |
| JSON в аргументах портится в PowerShell | агент должен положить JSON в файл и передать путь (это есть в руководстве) |
| Код выхода 2 | не прошла проверка: попросите показать сообщения проверок и поправить шаблон |
| Ответы на английском | задайте `PIXED_LANG=ru` или флаг `--lang ru` |
| Что-то упало или операция не сработала | **агент сам читает журнал** (`pixed log` или MCP-инструмент `read_log`): попросите «посмотри журнал и скажи, что упало». Можно и самому:  **Справка → Открыть папку журнала ошибок** в редакторе или `%AppData%\PixelEditor\logs\pixed-ГГГГММДД.log`. Записи на английском, со стеком; приложите их к сообщению об ошибке |

## 7. Безопасность

Давайте агенту рабочую копию, а не единственный оригинал. Просматривайте результат, прежде чем он что-то заменит. Ограничьте загрузки свободными лицензиями (CC0 или общественное достояние) и просите записывать источник рядом с результатом.
